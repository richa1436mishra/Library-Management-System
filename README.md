
# Library Management System

## Project Overview
A simple Library Management System developed in C++.

## Features
- Add books
- Display all books
- Search books by ID
- Issue books
- Return books
- Track available copies

## Technologies Used
- C++
- Object-Oriented Programming
- Visual Studio Code

## How to Run
Compile the program:

```bash
g++ library.cpp -o library
```

Run on Windows:

```bash
.\library.exe
```
